# Вода, канализация и доступные обращения: план реализации

> **For the agent:** REQUIRED SUB-SKILL: Use $executing-plans to implement this plan task-by-task.

**Goal:** Устранить перекрытие CTA уведомлением и подготовить две страницы центрального подключения с полезным подбором и измерением.

**Architecture:** Существующая статика, зелёный/оранжевый стиль КэпСтрой, прежние URL, навигация и контакты. Общие CSS/JS подбора без фреймворка и новых зависимостей; доставка через существующую форму /submit. Никакой вымышленной стоимости подключения или кейсов.

**Tech Stack:** HTML, CSS, vanilla JavaScript, Node test runner, Python unittest, установленный Playwright.

Авторизация: согласованный проект05.11, ответ команды09.11 и прямое поручение выполнить три ближайшие задачи. Выбор реализованной структуры уже сделан, повторное проектирование с новым согласованием не требуется. Подготовка страниц не означает публикацию или запуск рекламы. Факты: внешний docs/marketing/kepstroy-water-sewer-test-readiness-2026-11-05.md, дополнение09.11.
