## Изменения сайта

### Аналитика

- `callback_open` перенесён в общий обработчик открытия модального окна. Повторный вызов для уже открытой модалки не создаёт дубль.
- Явные якорные CTA `#request` / `#callback` учитываются только при наличии формы в целевой секции. Служебный переход `#main` не создаёт событие, даже если внутри main есть форма.
- `form_submit` остаётся событием успешной доставки формы; страницы благодарности сами его не генерируют. Реальные тестовые заявки в Telegram не отправлялись.
- Имена существующих целей совпадают с кодом; дублирующие цели в счётчике не создавались.
- Кэш-версии обновлены: `main.js?v=21`, `tracking.js?v=2`, включая исходные шаблоны генераторов.
- Нынешний режим Метрики сохранён: загрузка сразу, информационное уведомление и кнопка «Понятно». Закрытие уведомления не является включателем аналитики.
